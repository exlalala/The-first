## 数据结构 - C++ 实验作业库

本仓库用于记录个人在学习 C++ 与数据结构课程中的实验代码与作业，主要包含基础数据结构实现和算法练习。

### 代码内容说明

### 核心实验代码
*   **`Huffman_Tree/`**：赫夫曼树与编码。
    *   实现赫夫曼树的构建（按权值大小选择合并）。
    *   生成叶子节点的赫夫曼编码（左0右1）。
    *   实现对给定二进制序列的译码功能。
*   **`Graph_/`**：图的基本操作。
    *   实现图的**邻接矩阵**与**邻接表**两种存储结构构建。
    *   基于邻接矩阵的**广度优先遍历 (BFS)**（使用 `std::queue`）。
    *   基于邻接表的**深度优先遍历 (DFS)**（包含**非递归** `stack` 版和**递归**版）。
    *   实现统计连通分量（有向树）的个数。

### 数据结构基础练习
*   **`BiTree_/`**：二叉树的基本操作。
*   **`CrossLink/`**：十字链表实现。
*   **`Link List/`**：链表相关操作。
*   **`General_list.cpp` / `.h`**：广义表的实现。
*   **`顺序表-删除指定元素.cpp`** / **`顺序表-快速排序划分.cpp`**：顺序表（数组）的特定算法应用。
*   **`sqlist/`**：顺序表的基本操作。

### C++ 面向对象与特性
*   **`shape-homework.cpp`**：图形类的继承与多态实现。
*   **`template exercise.cpp`**：C++ 模板函数/类的练习。
*   **`年月日的符号重载.cpp`**：日期类的运算符重载（`+`, `-`, `<<` 等）。
